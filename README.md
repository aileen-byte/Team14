# How to run tb5 (Test bach 5)

1. Open a terminal
2. Go into folder tb5
   ```c
   cd tb5
   ```
3. Make the script executable
     ```c
   chmod +x ./assemble.sh
   ```
4. Now run
   ```c
   ./doit.sh
   ```
